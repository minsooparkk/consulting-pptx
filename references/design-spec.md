# 공통 디자인 규격

기본 기하·서식의 기계 판독값은 `../assets/design-tokens.json`에 있다. 사용자가 새 양식을 명시하지 않았다면 이 규격과 `../assets/consulting-template.pptx`를 사용한다.

## 역할과 우선순위

현재 사용자의 명시 지시 > 승인된 기존 양식 > 참고자료의 실제 시각 양식 > 기본값 순으로 적용한다. 제목/Header 구분, 근거의 정확성, 편집 가능성, Footer 제한은 유지한다. 스타일 수정 요청에 불필요한 내용 재작성을 섞지 않는다.

참고 PPTX가 슬라이드별 이미지 한 장으로 구성돼 있다면, 파일에 남은 Office 기본 테마와 Calibri 같은 기본값은 실제 시각 양식의 근거가 아니다. 화면에서 반복되는 위계와 색상을 분석한다. 이미지에서 정확한 폰트를 확인했다고 말하지 않는다. 지정 폰트 Pretendard가 있으면 그것을 우선한다.

## 글꼴

- 전체 패밀리: **Pretendard**. 한글·영문·표·도형·제목·Footer에 동일 적용.
- 제목: 30pt Bold. Header: 18pt Bold. 본문 소제목: 17~18pt Bold.
- 본문: 15~16pt Regular. 표 기본 14.5pt. 도식 14~16pt. Footer 10pt Regular.
- 표지 제목: 38pt Bold, 부제 22pt 내외. 두 줄 제목의 핵심 구절만 블루 강조 가능.
- 본문 글자는 14pt 미만으로 줄이지 않는다. 자동 축소보다 문장 압축과 페이지 분리를 택한다.
- 설치 여부와 실제 family/style을 확인한다. 지정 폰트가 없으면 설치 또는 대체 승인 필요를 알린다. 테마를 바꿨다고 글꼴이 설치·임베딩된 것은 아니다.
- 렌더링에 사용한 환경에 Pretendard가 없으면 대체 폰트로 렌더링됐을 수 있음을 밝힌다.

## 색상

| 용도 | HEX |
|---|---|
| 배경 | `#FFFFFF` |
| 기본 글자 | `#1F2937` |
| 보조 글자·Footer | `#6B7280` |
| 주 강조색 | `#1C3F7D` |
| 보조 블루 | `#2F5AA8` |
| 표 머리글·보조 결론 밴드 | `#16294F` |
| 연한 블루 영역 | `#EFF6FF` |
| 연회색 본문 영역 | `#F7F8FA` |
| 표·도형 구분선 | `#D7DCE3` |
| 옅은 블루 강조 | `#A9C2E8` |
| 제목 밴드 그라데이션 | `#0F1F3F` → `#1C3F7D` |

강조는 네이비·블루 한 계열 안에서 만든다. 의미가 같은 요소는 같은 색과 스타일을 쓴다. 다양한 원색이나 의미 없는 아이콘·이미지로 공간을 채우지 않는다.

## 일반 내용 슬라이드의 기하

16:9, 13.333333 × 7.5인치. 좌표는 좌상단 기준, 단위는 인치다.

| 요소 | X | Y | W | H | 서식 |
|---|---:|---:|---:|---:|---|
| 제목 밴드 | 0 | 0 | 전체 | 1.05 | 네이비 가로 그라데이션 |
| 제목 | 0.667 | 0.30 | 12.00 | 0.60 | 흰색, 30pt Bold |
| 구분선 | 0.667 | 1.05 | 12.00 | 선 | 블루, 1pt |
| Header | 0.667 | 1.275 | 12.00 | 0.90 | 짙은 회색, 18pt Bold |
| 본문 시작 | 0.667 | 2.475 | 12.00 | 하단 6.825까지 | 메시지별 자유 구성 |
| Footer 제목 | 0.667 | 7.125 | 11.10 | 0.225 | 회색, 10pt, 왼쪽 정렬 |
| Footer 페이지 | 12.05 | 7.125 | 0.617 | 0.225 | 회색, 10pt, 오른쪽 정렬 |

제목·Header·Footer 내부 여백은 0을 기본으로 한다. 제목/Header 줄 간격은 약 1.1배, 문단 앞뒤 간격은 0이다. 같은 요소의 좌표·크기·서식·여백은 페이지마다 변경하지 않는다.

네이비 밴드에는 **주제 제목**을 둔다. Header는 그 아래 **흰색 영역**에 둔다. Header가 짧아도 본문 시작을 올리지 않고, 길어도 본문을 밀거나 글꼴을 축소하지 않는다. 화면상 2줄을 우선하고 최대 3줄로 제한한다.

네이비 밴드 오른쪽의 옅은 각진 면은 템플릿 수준으로만 유지한다. 본문에는 그림자·입체효과·불필요한 둥근 장식을 추가하지 않는다.

## 본문 스타일

- 표: 짙은 네이비 머리글/흰색 Bold, 흰색·연회색 셀, 얇은 연회색 경계. 셀 여백과 정렬을 통일한다.
- 도식: 직각 사각형 중심. 기본 연회색/흰색, 중요 요소와 최종 단계만 블루 계열 강조.
- 연결선: 얇고 단순하게. 실제 순서·인과·전달 흐름이 있을 때만 화살표를 사용한다.
- 카드·단계 사이 간격은 약 0.27~0.40인치를 기본으로 하되 전체 정렬을 맞춘다.
- 보조 결론·운영 원칙이 필요하면 본문 하단에 네이비 밴드/흰색 글자를 사용한다. 기본 예시는 Y=6.13, H=0.67이다. 모든 페이지에 억지로 넣거나 Header를 반복하지 않는다.
- 보조 결론 밴드는 본문의 일부다. Footer의 내용·스타일을 바꾸는 수단으로 사용하지 않는다.

## 표지·예외 레이아웃

표지는 흰 배경, 높이 약 0.444인치의 얇은 상단 네이비 띠, 왼쪽 정렬의 강한 제목을 사용한다. 제목은 두 줄 가능하며 핵심 구절만 블루로 강조한다. 부제·발표자·기간은 제공된 내용만 쓴다.

목차·섹션 구분에는 별도 레이아웃을 허용하지만 글꼴·색상·Footer는 일치시킨다. 다른 화면 비율을 요청받으면 공통 양식을 먼저 재설계하고 그 결과를 전체에 동일 적용한다.

## Footer 제한

모든 슬라이드에서 왼쪽은 동일한 발표 전체 제목, 오른쪽은 실제 순서의 페이지 번호만 표시한다. 필요하면 전체에 사용할 축약 제목을 한 번 정한다. 현재 슬라이드 주제나 섹션명으로 바꾸지 않는다.

로고·날짜·별도 회사명·발표자명·기밀표시·출처·주석·장식은 Footer에 추가하지 않는다. 참고 양식에 있더라도 복제하지 않는다. 출처는 노트 또는 부록에 둔다.
